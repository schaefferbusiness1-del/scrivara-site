Or install manually / older method
  1. Click the button above — it saves a versioned MLS_Assist_v…zip to your Downloads. Create a new folder and unzip it there (right-click → Extract All).
  2. Open chrome://extensions and turn on Developer mode (top-right toggle).
  3. Already have an older MLS Assist? Click Remove on it first (so the new one replaces it cleanly).
  4. Click Load unpacked and pick the unzipped folder that contains manifest.json.
  5. Make sure you're signed in to MLS in a tab — no key to paste. Then open your Athena schedule and use 📅 Pull schedule in MLS.
If the schedule pull still says "older version" after this, double-check you clicked Remove on the old copy in step 3 — Chrome can otherwise keep running the old one.
