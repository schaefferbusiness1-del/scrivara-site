MLS Assist can read an Athena schedule only after the clinician starts the pull, and keeps review and final actions under clinician control. The package below is the exact released build the MLS app expects.

Released package SHA-256 digest: c71a63758cfd237bdd1041840ae750db6e1f578607e01970aa5cc4bb1e5d7c79. Verify the digest after downloading before you load or upload the package. Only this exact stamped release is distributed — loose source files and unstamped candidate ZIPs never are.
  1. Unzip the download. Mac: double-click the zip in Finder — it makes a folder next to it. Windows: right-click → Extract All.
  2. Remove any older MLS Assist first: open chrome://extensions and if an MLS Assist card is already there, click Remove. Two copies answer the same requests and break pulls — keep exactly ONE.
  3. On chrome://extensions, turn on Developer mode (top right), click Load unpacked, and pick the unzipped folder — the one containing manifest.json.
  4. Mac: also allow the microphone for Chrome in System Settings → Privacy & Security → Microphone, or dictation stays silent.
  5. Sign in to MLS in a tab — the extension uses that login automatically. Settings → Integrations shows the running version and tells you the moment you're up to date.
