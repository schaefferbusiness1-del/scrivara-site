🩺 MLS Assist

The clinician-started Athena companion for schedule pulls and review-first note placement. MLS Scribe is HIPAA compliant; use it only with your authorized, signed-in accounts.

Step 1 · Download

Get the extension

Use only the published channel: the Chrome Web Store listing or the exact stamped release ZIP with its printed SHA-256 digest. Loose or unstamped candidate files are never distributed.

Open the published channel

Do not remove a working extension to install loose or unstamped candidate files.

Step 2 · Sign in

Use your existing MLS session

  1. Install the published channel from the page above.
  2. Open MLS in a tab and sign in to your MLS account.
  3. Open Athena in its normal signed-in tab, then refresh the page once.
  4. Pin MLS Assist from Chrome's Extensions menu if you want quick access.

MLS Assist uses the signed-in MLS session. There is no extension API key to generate or paste.

Step 3 · Check site access

Site access — what Chrome will show

MLS Assist never asks Chrome for all-sites access, so in Chrome’s toolbar extension menu the broader “On all sites” choice shows grayed out. That is normal and correct — there is no all-sites permission to grant, and nothing is missing or broken. For clinical work it uses three: mlsscribe.com (the app), athenanet.athenahealth.com (your EMR) and scrivara-backend.onrender.com — the MLS backend that stores your account and the clinical content you send it. Chrome will also list the public review sites the reputation feature reads (Google Maps, Healthgrades, Vitals, WebMD, RateMDs, Zocdoc and similar) — those carry no patient data and are never used for clinical work.

  1. Right-click the MLS Assist icon in the toolbar and choose Manage extension (or open Chrome’s Extensions page and pick MLS Assist → Details).
  2. Under Site access, confirm both mlsscribe.com and athenanet.athenahealth.com are allowed — both toggles on.
  3. If Athena still is not detected: refresh the signed-in Athena tab once, and keep MLS signed in in another tab of the same Chrome profile.

Repeat this quick check on each new computer — Chrome grants these site permissions per machine.

Step 4 · Start the pull

Nothing reads silently

  1. In MLS, open Today, Calendar, or Menu → Staff prep & Athena month pull.
  2. Choose the date or range you intend to read.
  3. Start the schedule pull yourself and verify the provider, date, and patients before using the result.
How to use it

In the evaluated Athena workflow

  1. Work only in your own authorized practice and accounts.
  2. Open the extension panel or the matching MLS action yourself.
  3. Review every imported schedule row and every drafted note before any placement action.
  4. Confirm the active chart and destination again before copying or inserting content.

Safety boundary: the evaluated workflow is review-first and must stop before final Save, Sign, Submit, billing, or order actions. The clinician remains responsible for every final chart action. This page does not claim production clinical readiness.
